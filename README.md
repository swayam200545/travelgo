# TravelGo — Premium Smart Travel Gear Landing Page

## Description
TravelGo is a high-converting, modern landing page for a luxury smart travel backpack brand. Engineered with a glassmorphism design system, high-resolution product photography, interactive model customizer, side-by-side comparison matrix, customer testimonials, FAQ accordion, and interactive enquiry form.

## Technologies
- **HTML5**: Semantic structure, accessibility (`aria-*` roles, heading hierarchy).
- **CSS3**: Modern CSS design system (tokens, CSS Grid, Flexbox, backdrop-filter glassmorphism, responsive breakpoints).
- **Vanilla JavaScript**: Pure ES6+ interactive logic for variant selection, live price computation, smooth transitions, mobile menu, and form validation.

## Key Features & Highlights
- 📸 **High-Resolution Photography**: Photorealistic studio product shots for flagship hero, Lite (20L), Pro (28L), and Max (35L) models, plus 180° lay-flat internal organization, hydrophobic fabric close-ups, and airport lifestyle shots.
- 🎒 **Interactive Model Selector**: Real-time variant switching with thumbnail previews, dynamic specification updates (capacity, laptop size, weight), quantity adjuster, and live Indian Rupee (`₹`) price calculation.
- 🌟 **Visual Storytelling Showcase**: Grid cards featuring 180° TSA airport security lay-flat packing, weatherproofing, and luggage trolley ergonomics.
- 📊 **Model Comparison Matrix**: Detailed side-by-side comparison table for Lite vs Pro vs Max models.
- 💬 **Verified Buyer Reviews**: Customer testimonials with star ratings and verified buyer tags.
- ❓ **Interactive FAQ Accordion**: Toggleable answers to common questions about cabin compliance, USB charging, warranty, and delivery.
- 📋 **High-Converting Enquiry Form**: Client-side validated form with Indian mobile number formatting, field error highlights, and success confirmation box.
- 📱 **Mobile Sticky CTA Bar**: Fixed bottom action bar on mobile devices for seamless enquiry conversion.
